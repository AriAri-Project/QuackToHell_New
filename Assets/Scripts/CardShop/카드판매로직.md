## 카드 상점 판매 기능 흐름

### 1단계: 카드샵 UI 오브젝트 생성 (초기화)

**`CardShopModel.Awake()`** → **`CardItemFactoryManager.CreateTotalCardForSale()`**

- 게임 내 모든 카드 데이터(`AllCardsOnGameData`)에 대해 UI 오브젝트를 생성
- 모든 오브젝트에 `CardForSale` 태그 부여
- 생성 직후 모두 **비활성화** 상태로 대기

---

### 2단계: 카드 진열 (리롤)

**사용자가 카드샵을 열거나 리롤 버튼 클릭**

1. `CardShopPresenter.RequestShowCardShop()` 또는 `OnClickReRoll()`
2. `CardShopModel.TryReRoll()` → `DeckManager.RequestDisplayCardsServerRpc()`
3. **서버**에서 구매 가능한 카드 중 랜덤 5개 선택
4. 선택된 카드들의 상태를 `Solding`으로 변경
5. `CardShopModel.UpdateDisplayFromServer()`에서 해당 카드 오브젝트만 **활성화**하여 화면에 표시

---

### 3단계: 카드 구매

**사용자가 카드 클릭**

1. `CardItemView.OnPointerClick()` - `CardForSale` 태그 확인 후 이벤트 발생
2. `CardItemPresenter` → `CardShopPresenter.TryPurchaseCard()`
3. `DeckManager.TryPurchaseCardServerRpc()` - **서버에서 검증**
   - 인벤토리 한도 초과 체크
   - 카드 존재 여부 확인
   - 물량 초과 체크
   - 골드 잔액 확인
4. 검증 통과 시 `PurchaseCardResultClientRpc()` → `RequestUpdateCardStateServerRpc()`
   - 카드 상태를 `Sold`로 변경
   - 플레이어 인벤토리에 카드 추가

---

### CardForSale 태그 정리

| 태그 | 붙는 대상 | 용도 |
|------|----------|------|
| `CardForSale` | 카드샵 전시용 오브젝트 | 클릭 시 구매 이벤트 발생, 가격 표시 |
| `CardForInventory` | 인벤토리용 오브젝트 | 클릭 시 판매 이벤트 발생 |

**즉, `CardForSale` 태그는 "카드샵에서 판매를 위해 전시되는 UI 오브젝트"에 붙는 태그입니다.**

- 게임 내 모든 카드 데이터에 대해 카드샵용 오브젝트가 생성되고 이 태그가 붙지만
- 실제로 화면에 보이는 것은 서버에서 선택한 일부(최대 5개)뿐입니다
- 실제 판매 가능 여부는 `CardItemState`(None/Solding/Sold)로 관리됩니다
